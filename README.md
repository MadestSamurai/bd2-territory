面向 Windows 版 BrownDust II 的独立领地助手。自动采矿、砍树、按料理配比或固定作物种植与收获，支持可选自动料理，以及布局预检、购买和导入。

## 下载

当前版本：**0.3.7-beta.1**。一个程序内置简体中文与 English，可在右上角切换。Beta 版建议先用小预算、少量料理确认效果。

| 版本 | 运行环境 | 建议 |
| --- | --- | --- |
| **Portable** | 自带 .NET，无需另装运行库 | 大多数用户选择此版本 |
| **Lite** | 需要 [.NET Desktop Runtime 8 x64](https://dotnet.microsoft.com/en-us/download/dotnet/8.0) | 已安装桌面运行库、希望减小下载体积 |

仅支持 Windows x64。两版功能相同；EXE 可单独使用，ZIP 附带双语说明与许可证。用 `SHA256SUMS.txt` 核对文件。无需 Python、.NET SDK 或其他 BD2 工具。Lite 需要 **Desktop Runtime**，普通 .NET Runtime 不够。

## 快速开始

1. 启动游戏并进入自己的 Fantasia Territory，保留一个游戏实例。工具与游戏使用相同权限。
2. 打开工具，点击 **连接／更新组件**，等到显示“领地已识别”。
3. 勾选采集项目，在「种植与料理」选择**按料理配比种植**或**固定种类作物**。连接后读取实际名称与解锁状态；固定模式只反复种所选作物。
4. 设置播种预算后点击 **开始自动化**。默认预算 1400、间隔 500ms；预算 0 为不限。
5. 点击 **暂停** 或关闭工具停止后续操作，已提交的动作仍等待游戏正常结算。

从私有领地 0.2.0 升级，可先暂停旧工具后连接更新，游戏无需重启；已有其他独立工具或工作台组件时，需要先正常重启游戏再切换。双击程序不会自动连接或开始采集。

## 功能与设置

| 设置 / 功能 | 行为 |
| --- | --- |
| 采矿、砍树 | 只采集完全成熟的资源；失败目标留在重试队列 |
| 种植与收获 | 同种作物每批 100 格，按库存与已种数量平衡原料；需要连片的 100 块农田 |
| 固定种类作物 | 每批同种 100 格，收获后继续种植所选作物；更改选项等当前批次确认后生效，可同时使用自动料理 |
| 配方 | 从当前游戏读取名称、原料、种子与解锁状态；换配方等本批播种确认后生效 |
| 默认配方 | 活力面疙瘩，原料比例 5:3:2；具体名称跟随客户端翻译 |
| 自动料理 | 默认关闭。制作所选料理，消耗已有原料；每批上限 1–1000，默认 100；原料或成品容量不足时继续其他项目 |
| 移动 | 默认 A*，必要时细化窄路网格；复用地面和路线缓存，按游戏角色碰撞、台阶与坡度规则预测通行；保留载具赶路与短距冲刺脱困 |
| 使用游戏 NavMesh 寻路 | 可选、默认关闭；关闭时立即切回 A*，开启从下一次移动生效，选择自动保存 |
| 操作间隔 | 100–60000ms，默认 500；仍须等待游戏动画、加载和服务器响应 |
| 播种预算 | 每次启动重置，用完仍可采集；只约束播种，料理消耗已有原料 |
| 布局 | 农田／矿场／林场模板或 JSON 导入；先预检占地与费用，再点击购买并导入 |

新安装和旧版升级均默认关闭 NavMesh。A* 暂时找不到路线时会保留目标、稍后重试，不会自行开启 NavMesh。水面禁止通行，只能经过已放置的桥梁；绕行、试探及冲刺均遵守此规则。NPC 和工人不再被人为增加占位；只有游戏实际生效的碰撞参与预测。预测无路时允许普通移动验证，连续 3 秒没有实际推进才临时排除该处。

自动料理不会购买原料、出售物品或切换料理。结果未知时保留记录并暂停，避免重复消耗；请核对游戏库存与诊断，不要删除记录盲目重试。

## 布局工具

暂停自动化后进入 **布局工具**，选择区域与模板或载入布局文件，点击 **预检布局与费用**。预检通过后确认清单并点击 **购买并导入**。

优先复用和移动同类设施，只补买不足部分。装饰使用游戏价格，建筑使用已有建材，制作家具必须已有库存。保留其他建筑、工人和作物，不买地、不拆除；被占位置需先腾空。导入前保存布局备份，每处摆放等待回读。

**导出当前领地** 保存可编辑建筑和装饰的位置，不含账号或工人身份。布局只能用于相同地形、已经解锁的区域。

## 界面语言

首次启动跟随系统语言，右上角切换独立保存，不会开始、停止或重新配置自动化。料理、作物和设施名称跟随游戏语言；原始日志及底层异常保留原文。

## 兼容与限制

连接时读取本机客户端接口并生成适配组件，不绑定某个发布日期的客户端。不兼容变化会停止连接；不保证所有未来版本兼容。

程序不包含游戏 DLL、静态表、图片、账号资料或私人布局。源码可在未安装游戏的电脑上构建；连接需要本机 Windows 官方客户端，不支持安卓模拟器。

## 诊断与反馈

在 **连接与运行诊断** 查看状态；数据位于 `%LOCALAPPDATA%\BD2Territory`，不上传。包括设置、账号进度、料理记录、布局备份和障碍现场。

反馈请提供版本、错误文字与复现步骤，只分享必要日志，不上传账号凭据或完整游戏资源。保留首条连接错误，避免反复连接掩盖原因。
